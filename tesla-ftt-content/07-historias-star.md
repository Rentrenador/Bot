# 6 historias STAR que debes preparar

Método **S**ituation → **T**ask → **A**ction → **R**esult.  
Estas son **plantillas de práctica del candidato**, no preguntas filtradas de Tesla ni “respuestas correctas oficiales”.

### Tips de formato (UI)

- 60–90 segundos oral / ~150–220 palabras escritas.  
- 1 métrica o resultado observable si existe.  
- Termina con aprendizaje transferible a Sales / Delivery / Ops.

---

## 1. Ownership (me lo quedé hasta el final)

**Prompt:** Cuenta una vez en la que un problema “no era tuyo” pero lo resolviste de punta a punta.

| | Escribe aquí |
|---|---|
| **S** | Contexto, stakeholders, por qué importaba al “cliente” |
| **T** | Qué ownership decidiste asumir |
| **A** | Pasos concretos (comunicación, escalado, seguimiento) |
| **R** | Resultado + qué harías igual/diferente |
| **Puente FTT** | Cómo aplica en handoff Sales→Delivery→Ops |

**Palabras ancla:** accountability, cierre, handoff limpio.

---

## 2. Información incompleta (decidí igual)

**Prompt:** Situación con datos insuficientes y deadline. ¿Cómo priorizaste y comunicaste el riesgo?

| | Escribe aquí |
|---|---|
| **S** | Ambiguo / urgente |
| **T** | Decisión o avance requerido |
| **A** | Qué info buscaste, qué asumiste, a quién alineaste |
| **R** | Outcome + mitigación si te equivocaste |
| **Puente FTT** | Retail y Ops viven con cola y cambios de última hora |

**Palabras ancla:** trade-offs, hipótesis, comunicar riesgo.

---

## 3. Customer recovery (recuperar a alguien frustrado)

**Prompt:** Cliente/usuario enfadado. Cómo pasaste de conflicto a confianza.

| | Escribe aquí |
|---|---|
| **S** | Qué falló (expectativa vs realidad) |
| **T** | Recuperar experiencia sin prometer lo imposible |
| **A** | Escucha, empatía, opciones, follow-up |
| **R** | Feedback del cliente / retención / aprendizaje de proceso |
| **Puente FTT** | Delivery day y postventa |

**Evita:** culpar a “la empresa” delante del cliente; inventar compensaciones.

---

## 4. Feedback (lo pedí, lo recibí o lo di)

**Prompt:** Momento en que el feedback cambió tu comportamiento o ayudaste a otro a mejorar.

| | Escribe aquí |
|---|---|
| **S** | Relación / equipo |
| **T** | Mejorar rendimiento o dinámica |
| **A** | Cómo diste/recibiste feedback (específico, respetuoso) |
| **R** | Cambio observable |
| **Puente FTT** | Assessment grupal + rotaciones con reviews |

---

## 5. Calidad vs velocidad (no sacrifiqué lo crítico)

**Prompt:** Presión de tiempo vs estándar de calidad/seguridad. Qué protegiste y por qué.

| | Escribe aquí |
|---|---|
| **S** | Deadline vs riesgo |
| **T** | Entregar a tiempo sin dañar seguridad/calidad |
| **A** | Criterios, qué cortaste, qué no |
| **R** | Resultado + cómo evitaste retrabajo |
| **Puente FTT** | Entrega de vehículo: velocidad con checklist |

---

## 6. Autoaprendizaje (me enseñé algo difícil)

**Prompt:** Aprendiste una skill o dominio sin curso formal, bajo presión.

| | Escribe aquí |
|---|---|
| **S** | Gap de conocimiento |
| **T** | Qué necesitabas dominar y para cuándo |
| **A** | Fuentes, práctica, mentores informales, errores |
| **R** | Evidencia de competencia |
| **Puente FTT** | Self-starter del programa |

---

## Mini-rúbrica (autoevaluación)

- [ ] ¿Se entiende el impacto en 10 segundos?  
- [ ] ¿Tus **Actions** son tuyas (verbos en primera persona)?  
- [ ] ¿Hay resultado (aunque sea aprendizaje duro)?  
- [ ] ¿Evitas jerga interna inventada de Tesla?  
- [ ] ¿Puedes contar la misma historia en español e inglés B1+?

## Banco de ganchos (elige 1 por historia)

- “Había un cliente esperando y el proceso estaba roto…”  
- “Nadie era dueño del follow-up…”  
- “Teníamos 2 horas y un estándar de calidad no negociable…”  
- “Me dieron feedback que dolió — y tenía razón…”
