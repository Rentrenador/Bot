    Cómo hemos calculado tu resultado

    Cada ítem Likert RIASEC (Q01–Q30) está etiquetado con una letra (R/I/A/S/E/C). Calculamos la media por letra, ordenamos de mayor a menor y formamos un código Holland ilustrativo de 2–3 letras. Los clusters se puntúan como suma(medias primary) + 0,5 × suma(medias secondary). Las preferencias prácticas (Q31–Q34) no entran en la media RIASEC.

    Límites: ~34 ítems de autoinforme. Orientación inspirada en el modelo Holland/RIASEC; no es SDS licenciado ni test clínico validado; no hay estudio de fiabilidad reportado.
