    Cómo hemos calculado tu resultado

    Cada opción del test lleva etiquetas (tags) hacia clusters de grados. Las respuestas únicas y múltiples suman peso a esos clusters; las escalas 1–5 aportan un peso menor (valor × 0,4) para no saturar frente a intereses. Se muestran los clusters con mayor puntuación relativa.

    Límites: 18 ítems de autoinforme. No es un test psicométrico clínico ni una prueba de admisión universitaria.
