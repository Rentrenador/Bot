# Universidades de ejemplo por cluster — UniTalent MVP

**Importante:** listados **ilustrativos** para el prototipo (2026-09-21).  
**No son rankings oficiales** ni un aval del Ministerio. La oferta de grados, campus y plazas cambia cada curso.

**Verifica siempre:**
- [RUCT](https://www.educacion.gob.es/ruct) — Registro de Universidades, Centros y Títulos  
- [QEDU / notas de corte](https://www.educacion.gob.es/notasdecorte) — datos de acceso y centros  
- Web de cada universidad (planes de estudio vigentes)

Se priorizan **universidades públicas**. Se incluye la **Universidad de Alcalá (UAH)** donde encaja de forma razonable con la oferta típica.
